## 2. 查询、适用性与采纳决策

所有查询都从安装后的绝对脚本路径运行。搜索结果是建议，项目事实和用户指示优先。只有适合问途的建议进入规划，不将整个自动生成方案直接当成已确定设计。

| 查询 | 模式与结果 | 决策 |
|---|---|---|
| travel tourism platform | design-system，返回 Scroll-Triggered Storytelling、Aurora UI、旅游蓝橙色与 Noto Sans Thai | 采纳章节叙事与蓝色旅游意象；保留普通阅读顺序；Aurora 风格不作为选定方向；泰文字体与本项目不匹配 |
| Chinese multilingual editorial | typography，首位 Chinese Simplified，Noto Sans SC | 采纳中文无衬线排版及本地字体可选方案，覆盖不适合中文的字体推荐 |
| editorial minimalism premium | style，返回 active 的 Minimalism & Swiss Style | 采纳留白、网格、清晰层级与轻量效果；颜色改为已有问途品牌体系 |
| React 18 lazy route splitting | react stack，返回 legacy/deprecated 的 Compiler 与 forwardRef 相关建议 | 结果偏离延迟加载问题，也不适合据此更改 React 18；不采纳，并缩窄查询重试一次 |
| lazy code splitting | react stack，首位 Lazy load components | 采纳 React.lazy 延迟加载这一兼容 React 18 的通用 API；目录中的 react 19.2.x 标记不作为升级指令；其他 props 建议与本次问题无关 |
| reduced motion scroll | ux，返回 Reduced Motion、Motion Sensitivity、Smooth Scroll | 采纳减弱动画与直接可读状态；平滑滚动仅在用户允许动画时使用 |

本轮未将包含不匹配子项的自动设计系统持久化为 MASTER.md。正式设计系统在用户确认方向后，由上述已筛选原则与问途品牌色共同形成。
