## 实现边界

视口使用容器的 `clientWidth`，SVG 画幅与实际可见内容宽度一致。地名以 14px 计算，与缩放分别排布；临近参考点的数字徽标可移开，并以细引线连接原始点位。路线全览包含当前路线、上一版与选中参考点；全部地点保留十点目录。缩放后四向按钮可沿目录边界平移，屏外地点仍保留在 DOM 地点列表，点击后返回地图视区。地图获得焦点时，方向键平移、`+`/`−` 缩放、`Home` 全览；图上地点也支持 Enter 与空格选择。

保留 `data-map-kind="schematic-wgs84"` 与 `data-place-id`；增加 `data-map-view`、`data-map-zoom`、`data-map-width`、`data-map-height` 和 `data-map-label` 供浏览器验证。共享文字函数只更新来源边界说明，其调用签名、顺序列表与版本比较逻辑不变。
