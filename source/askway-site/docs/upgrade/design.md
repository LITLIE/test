# 问途官网体验改造设计 · 2026-11-24

执行依据为用户提供的《问途官网改造指南》1.1 版及实施任务清单。用户已授权完成前端改进，沿用推荐视觉方向与 R0—R5 范围；常规实现选择在此范围内自主完成。

采用纸白、深海蓝、琥珀强调色与程序化纸艺城市。首页保留纪实海岸和轻量品牌叙事，增加清晰的体验入口。体验页采用三栏工作台：可修改条件、同数据地图、路线与候选差分；手机顺序阅读并提供区域切换。

公开资料、规则规划、版本状态、图形展示分别实现。参考坐标使用 WGS84 并标记为参考点、入口未核实；开放、费用与无障碍信息未知时保留未知。路段由参考坐标的直线距离和公开的演示估算策略得到，几何明确标为示意，不能用于导航。

三种任务模板进入同一条件模型。核对条件后生成候选，首次生成也需要明确采用。新草稿保留旧方案独立快照；候选绑定会话、草稿、请求和基线，过期结果不能覆盖最新状态。采用与撤销不由动画触发。

二维 SVG 地图和按需加载的 Three.js 场景使用同一份方案和选中地点。三维只在用户选择后进入客户端，使用程序化几何与显式缩放、旋转、复位控制；失败、后台或离开视区时保留完整二维与文字操作。时间轴预演可暂停和打断，减弱动画直接展示最终状态。

保留原产品页三点回归演示并明确其范围，/product/#demo 继续可用，同时导向新 /experience/。合作草稿和真实邮箱继续可用；软件下载仍显示待开放。真实服务、定位、公开仓库、外部邮件与网站发布不进入本地改造范围。
