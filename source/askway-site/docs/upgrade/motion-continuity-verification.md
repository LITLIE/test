# 问途 3.2.1 连续空间转场细化验收

**日期：2026-11-28，Asia/Hong_Kong。** 用户反馈原转场过快、画面突变，并明确选择保留实景照片、增加连续景深空间转场与 3D 粒子。本轮围绕这一反馈细化首页镜头，不替换原摄影、业务规则或手机正常阅读模式。

实现范围为 **照片的 CSS 3D 空间层，以及 XYZ 粒子经透视计算投影到 2D Canvas**。照片仍是有署名的平面摄影，并未重建照片中的建筑、生成测绘模型或制作连续视频。没有新增位图资产文件或依赖；三张光晕 sprite 只在内存 Canvas 中生成。

## 从突变到连续交接

| 调整 | 实际变化与目的 |
| --- | --- |
| 主舞台长度 | 260svh 增至 480svh；1440×1000 下有效滚动距离由 1600px 增至 3800px，让同一组镜头有更长的观察与交接距离。进度继续由实际几何计算。 |
| 视觉追随 | 原生滚动目标 `targetValue` 与渲染 `value` 分离，以 160ms 时间常数有限追随；它不是所有输入都在 160ms 完成的承诺。快速反向立即使用最新目标，不累积过冲；暂停、离屏和重复当前 hash 定位即时 snap。 |
| 全段空间关系 | 摄影与粒子读取同一个 `cameraPose`，转角限制在 2° 内，深度位移限制在 120px 内。照片通过 perspective、translate3d、rotateX/Y、浅景深与细微缩放形成连续空间层。 |
| 路线进入近景 | 近景从实测共享路线的日月贝终点，以零大小窗口展开至整张照片；海岸背景在展开过程中继续覆盖舞台，避免只切换图片造成空白或突跳。 |
| 近景进入产品 | 近景文字在 p=.78 前退出；p=.78–.94 摄影退入实测产品卡片媒体矩形；地图自 .94 起进入，产品文字自 .96 起进入。稳定产品锚点改为 .985，让定位后文字与控件已经清楚可用。 |
| 章节栏与导航 | 删除章节栏按 phase 蓝/白硬翻色。修复 clear 导航的白色品牌与 250ms 白背景过渡不同步问题，使背景、文字及品牌切换协调。 |

手机保持独立竖版摄影、静态章节和正常阅读；不强制应用桌面长 sticky 镜头。暂停和降级继续保留页面几何、原生滚动与 HTML 内容。

## 粒子与调度

粒子拥有 XYZ 坐标、透视大小、远近辉光及连续色彩变化。复用三个 64×64 内存光晕 sprite，桌面/手机分别保持 280/100 点，按 60/30Hz 实际限绘；这两个上限是调度策略，不是已测硬件帧率。

摄影、粒子及进度继续共享唯一 rAF 控制器。暂停、系统减少动态、省流、后台、离屏与展示 owner 约束保留；销毁时取消调度并释放内存 sprite。已形成的路线保持确定性终点，反向滚动不依靠累计帧号。正文、锚点、按钮和署名仍由 HTML 提供，手动相机和工作台状态不因自动展示改变。

核心源码为 `src/features/cinematic/progress.ts`、`useStoryProgress.ts`、`cinematic.css`、`storyConfig.ts`、`src/motion/seaRouteMath.ts` 与 `src/components/SeaRouteParticles.tsx`。
