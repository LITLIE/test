## 复现与输出范围

```sh
node tests/experience/quality.mjs --axe-only
node tests/experience/quality.mjs --lighthouse-only
```

完整测量可运行 `node tests/experience/quality.mjs`；性能阶段应在其他浏览器任务结束后运行。脚本只调用已安装库，未调用依赖安装或生命周期脚本。

所有截图与报告位于工程的 `delivery/quality/`；浏览器配置、缓存和 crash 目录均从工程根路径推导，位于 `.agent_tmp/` 与 `.agent_cache/`。`TEMP`、`TMP`、`APPDATA`、`LOCALAPPDATA` 仅在当前进程及其浏览器子进程内重定向，浏览器关闭后清理独立配置目录。Lighthouse 使用显式 `chromePath`、`userDataDir`，并在 `finally` 中释放进程。
