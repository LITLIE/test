# 问途官网 3.1 · 美化与验收记录

本轮依据用户的《问途官网前端改造指南》，以 `262872ae7f6baac08ab7b6efe30765ef5e1e79a3` 为基线。该提交是 React 静态预渲染的五页官网，源码在 `source/askway-site/`，仓库根目录是发布产物；旅程工作台已有公开参考资料、条件核对、候选比较、采用与撤销，三维展台独立管理资源和滚动状态。

本地原 `askway-site` 是更早的 2.0 副本并有未提交改动，因而在工作区内新建 `askway-web` 副本，分支为 `feat/coastal-visual-refresh`。原副本没有被修改。子智能体仅使用 `gpt-6.1-sol`。

## 最终画面

- 首页：保留珠海实景与「让城市探索，自有方向。」；桌面以大幅建筑与左侧标题形成构图，手机单独校准裁图。移除首屏并排主按钮、装饰路线和单张摄影的轮播编号；旅程体验仍是常规导航。
- 海面到路线：在首页摄影与 `#story` 之间加入按可见性懒加载的 Canvas 2D 光点。稳定起点、深度与终点用统一滚动进度插值，正滚和倒滚使用同一组坐标。海滨公园、香炉湾、日月贝以 HTML 显示，静态路线不依赖脚本。
- 产品：纸白双栏首屏直接展示三站关系；保留一条自然体验文字入口、三维展台、原三点演示和下载状态，压缩重复介绍。
- 关于：建筑局部实景与标题错位，光扫只在照片内播放一次；正文、资料范围、价值与阶段留白。
- 合作：宽目录式合作方向与一次边缘光扫；`#contact` 是安静的表单背景，焦点、错误、草稿和复制反馈保持清楚。
- 共享动态效果：44px 暂停控件有可访问名称，偏好跨官网切页保持。后台、离屏、系统减少动态效果和可见实时展台会停止粒子连续绘制；路线成形后也停止连续帧。文字区域有独立遮罩与前景层级，体验路由退出网站装饰层。

## 日月贝与资源

壳板、铺装、沥青分别使用原创 1024px 法线和粗糙度，数据贴图保持非颜色空间；板缝按像素导数抗锯齿，远景减小对比。玻璃上沿与分格采用同源曲线，近景玻璃和背景楼群分别控制反射。合并栏杆、三级台阶、护岸立面与贴水湿石暗带提供尺度。HDR 方位与太阳方向校准，离线日景／黄昏反射分别缓存并可往返复用。

## 滚动与海面的独立记录

普通页面在同一主机、相同像素范围下各采样 10 秒正滚／倒滚，先将实时展台锁为暂停。该 headless 主机的 rAF 调度约 240Hz；下表是调度观察间隔，不是手机 GPU 或绘制耗时。

| 普通滚动 | p50 / p95 / 最大间隔 | 超过 33ms | Long task |
| --- | --- | ---: | ---: |
| 基线 1440px | 4.2 / 4.3 / 12.5ms | 0 / 2395 | 0 |
| 3.1 1440px | 4.2 / 8.4 / 24.9ms | 0 / 2097 | 0 |
| 基线 390px | 4.2 / 4.3 / 12.4ms | 0 / 2399 | 0 |

另以 Edge SwiftShader 测海面 10.0405 秒：观察到 29 次输出，约 2.89 次／秒；31 次实际 draw calls、64,978 三角形、DPR1。渲染观察间隔 p50 370.8ms，不能声称这台软件 WebGL 已达到 30fps，也不能由它推断真机 GPU。所有采样无 JS 错误。

正滚／倒滚另保存 84 帧、8.4 秒、960×667 的原始 GIF；录制期间的帧间隔没有用于性能判断。精选压缩副本保留相同帧数和时长。
