# 日月贝近景与材质验收

本批以 `262872ae7f6baac08ab7b6efe30765ef5e1e79a3` 为基线。原始三张插图与原清单保存在 `before/`；新 PNG、白天近景和捕图清单保存在 `after/` 与 `illustration-renders.json`。

## 实際改善

- 大小贝比例保留；薄壳板缝按像素导数抗锯齿，远景降低对比。玻璃上沿调整为浅弧面，并与分格线同源。
- 壳板、铺装、沥青分别使用原创 1K 法线及粗糙度；数据空间正确。铺装 UV 按约 1 米单元校准，颜色由材质承担；金属和近景玻璃与背景楼群玻璃分别控制。
- 三级台阶和合并栏杆提供尺度。护岸跨越海面高度，外法线朝海；湿石暗带在最终黄昏及白天近景中可见。
- HDR 最亮方向与太阳方位对齐。离线天空反射按日景、黄昏分别缓存，仅捕捉天空；往返切换复用对应缓存。海面仍按原有约 30 帧调度并尊重暂停、离屏、后台和减少动态效果。

静帧实测统计：全景 72,564 三角 / 40 calls；黄昏近景 64,978 / 31；路线 72,568 / 41。与预计统计的差异来自视角裁剪和隐藏背景组。

新 WebP 总计 480,824 字节，原版为 468,006（增加 12,818）。六张 1K 材质共 746,226 字节；文件及解码 RGBA 的 SHA 均核验。来源、作者、生成方式、许可和公开文件 SHA 见 `public/assets/realism/sources.json`、`illustrations.json` 与 `public/asset-credits.json`。

全景和黄昏近景的机位及视口保持原预设。路线原脚本使用无效的零会话/草稿版本，导致静默空方案；已改为有效版本并要求真实 proposal，路线镜头因此按实际候选点重新拟合，不能当作完全同机位的前后对比。

## 实际限制

模型仍为场景示意。环境只校准 HDR 方位，没有重建 HDR 太阳高度与现场光度。新增 1K 未压缩纹理及 mipmap 约增加 32 MiB GPU 内存。验证使用 Edge 软件 WebGL，未覆盖真实手机 GPU、Safari 或真机帧时间。本批未制作短片。

所有工具临时、缓存、浏览器 profile 与输出均在项目内；Pillow 12.3.0 使用已有环境，以 `-B` 和 `PYTHONDONTWRITEBYTECODE=1` 调用。没有安装依赖、浏览器或编码器，也没有修改全局配置。
